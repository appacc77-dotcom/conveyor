# design/figma — вход и выход пайплайна Figma

Каталог заведён при перезапуске проекта 06.11.2026. Здесь лежит всё, что
превращает `.fig` в проверяемые факты. Ни один файл отсюда не правится руками:
это выход скриптов.

| Каталог | Фаза | Что внутри | Кто создаёт |
|---|---|---|---|
| `canvas/` | P0 | экспорт канваса 1:1 (PNG) — эталон для кропов | человек / мост Figma |
| `extracted/` | P0 | разбор `.fig`: узлы, переменные, стили, `manifest.json` с хешем | `figma-extract` |
| `spec/` | P2 | `<page>.json`: секции → компоненты → боксы → тексты → ассеты | `figma-resolve` |
| `crops/` | P3 | `<component>.png` — эталон приёмки, вырезан из `canvas/` | `figma-crops` |

## Источник

Сам `.fig` весит 106 MB и в проект не копируется — он лежит рядом:

```
../syntonia-deepseek/design/figma/Website Syntonia.fig
```

Хеш и версия фиксируются в `extracted/manifest.json` на шаге P0. Без хеша
любое число в отчёте — воспоминание, а не проверка.

## Порядок

```
canvas/ ──► crops/        (вырезание по bounds, 1:1)
.fig   ──► extracted/ ──► spec/ ──► src/components/ds/
```

`crops/` и `spec/` собираются из **одного и того же** источника. Если кроп и
spec расходятся — чинится spec, а не вёрстка.
