## Агенту и инженеру

**Изменения конвейера в этой публикации:**

| что | где |
|---|---|
| экспорт из архива читает шрифт из стиля и высоту строки в процентах | `tools/fig-kiwi.mjs` |
| карта страниц + ворота `coverage-map` | `tools/page-map.mjs`, `checks.json` |
| отступление по `file.key` учитывается в контракте спеки | `check-spec-contract.mjs` |
| карта пишется только по `--write` | `tools/page-map.mjs` |

**Чему научились (записано):**

- в архиве `.fig` у текстового узла `fontName` бывает устаревшим — актуальный
  шрифт лежит в стиле (`styleIdForText`). Проверено: без этого в hero
  подставлялся Cormorant вместо Literata;
- ворота не имеют права писать файлы во время прогона: карта пересобиралась
  прямо в приёмке, и прогон переставал доказывать коммит;
- глобальный мобильный CSS не работает при 26 компонентах с inline-позициями.
